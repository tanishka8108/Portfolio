# Tanishka Randive — Developer Portfolio

Dark responsive React + Vite portfolio.

## Run locally
```bash
npm install
npm run dev
```

## Production check
```bash
npm run build
npm run preview
```

## Resume PDF
A copy of your uploaded resume is included at `public/TANISHKA_RANDIVE_Resume.pdf` for the View Resume button.

## GitHub project links
Project cards link to repositories visible on the `tanishka8108` GitHub profile. Check that each repository is the correct version before sharing with recruiters.

## Deploy
Push this project to GitHub and import it into Vercel. Build command: `npm run build`; output directory: `dist`.
